# Виджет «что играет» для панели задач Windows 11

Мод для [Windhawk](https://windhawk.net): показывает текущий трек на панели задач,
между кнопками приложений и треем.

* обложка, название трека и исполнитель;
* кнопки **назад / пауза-плей / вперёд**;
* прогресс-бар с временем, по нему можно кликать, чтобы перемотать;
* живой **визуализатор** — штрихи двигаются под то, что реально звучит.

Работает с Яндекс Музыкой и с любым плеером, который показывается в оверлее
громкости Windows (Spotify, браузер, VLC). Виджет сам следует за тем плеером,
который играет сейчас.

## Требования

* Windows 11;
* установленный [Windhawk](https://windhawk.net) (мод собирается его компилятором).

## Установка

Мод работает внутри `explorer.exe`, поэтому перед установкой стоит создать точку
восстановления системы.

```powershell
# PowerShell от имени администратора
Checkpoint-Computer -Description "Before taskbar media widget" -RestorePointType MODIFY_SETTINGS

git clone https://github.com/LadaBakanova/taskbar-media-widget.git
cd taskbar-media-widget
powershell -ExecutionPolicy Bypass -File install-and-verify.ps1
```

Скрипт запросит подтверждение UAC, соберёт мод, установит его в Windhawk и
проверит результат. После этого запустите музыку: виджет появится на панели
задач.

Если рядом включены `Taskbar multi-tray` или `Windows 11 Taskbar Styler`, при
первой проверке их лучше выключить на время, чтобы сразу видеть, что делает этот
мод. Стилер, наоборот, полезен: фон и рамка виджета берутся из его темы.

**Обновление:** `git pull` и снова `install-and-verify.ps1`. Настройки при этом
сохраняются.

## Настройки

Настройки открываются в Windhawk, на странице мода.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| `taskbarMonitor` | `screen1` | На каком экране показывать виджет: 1 — основной, 2–4 — дополнительные |
| `visualizer` | включён | Двигать штрихи под музыку |
| `visualizerGain` | 100 | Чувствительность визуализатора, %: больше — штрихи выше |
| `visualizerFps` | 33 | Частота кадров визуализатора |
| `showProgressBar` | включён | Показывать прогресс-бар |
| `seekOnClick` | включён | Перемотка по клику на прогресс-баре |
| `followTaskbarTheme` | включён | Брать фон, скругление и рамку из темы Windows 11 Taskbar Styler |
| `backgroundBlur` | включён | Матовое стекло под виджетом |
| `opacity` | 255 | Непрозрачность панели (255 — полностью непрозрачная) |
| `rightMargin` | −2 | Зазор до системного трея, px |
| `widgetWidth` | 419 | Ширина виджета, px. Меньше 419 нельзя: раскладка рассчитана на эту ширину |
| `widgetHeight` | 42 | Высота виджета, px |
| `pollIntervalMs` | 400 | Как часто опрашивается плеер |
| `fallbackRightOffset` | 220 | Запасной отступ от правого края, если трей не найден |
| `forceTopmostEveryTick` | включён | Каждый тик удерживать виджет поверх панели |

## Если что-то не так

**Панель задач зависла.** Запустите `recover.cmd` от администратора: он
останавливает Windhawk и перезапускает explorer без модов.

**Виджета нет.** Убедитесь, что мод включён в Windhawk и что музыка действительно
играет (без активной медиасессии виджет скрыт). Проверка:

```powershell
python check-installed.py
powershell -ExecutionPolicy Bypass -File check-loaded.ps1
```

**Виджет тормозит или кнопки отзываются с задержкой.** Выключите визуализатор
(`visualizer`). Если не помогло, посмотрите в Диспетчере задач процесс «Яндекс
Музыка»: когда он долго занимает 40–50 % процессора, причина в нём.

**Виджет выглядит сплошной тёмной плашкой.** Windows отключает эффекты
прозрачности (режим экономии энергии, удалённый сеанс). Выключите `backgroundBlur`.

**Прогресс-бар отстаёт.** Яндекс Музыка не сообщает позицию во время обычного
воспроизведения, поэтому виджет считает время сам и поправляет его при перемотке,
паузе и смене трека. Уменьшите `pollIntervalMs` до 250.

**Визуализатор не двигается.** Он слушает устройство воспроизведения Windows по
умолчанию: проверьте, что звук идёт именно через него и что плеер не использует
эксклюзивный режим (WASAPI exclusive).

**Штрихи слишком низкие.** Увеличьте `visualizerGain`. Уровень зависит от громкости
Windows.

**Виджет наезжает на иконки или стоит не там.** Измените `rightMargin` или
`taskbarMonitor`. Передвинуть виджет можно и скриптом `set-right-margin.ps1`.
